🎬 Demo — Workflow Designer (15-20 min)

1. Contexto (1 min)

Explicar brevemente: "Sistema para gestionar trámites institucionales mediante políticas de negocio"
Mostrar los 3 roles: Admin, Funcionario, Cliente


2. Admin — Crear política (4 min)

Entrar como Administrador
Crear política "Solicitud de crédito"
Mostrar el editor con calles por departamento
Usar el asistente IA por voz — dictar: "agrega una actividad de validación en el departamento de Riesgos"
Mostrar que el diagrama se actualiza solo
Mostrar el colaborativo — abrir segunda ventana, mover un nodo y que se actualice en la otra


3. Admin — Diseñar formulario (2 min)

Click en "Diseñar formulario" de una actividad
Agregar campos: texto largo, select con opciones, fecha
Guardar
3. Admin — Diseñar política completa (4 min)
Editor manual:

Arrastrar nodos, conectar actividades

Flujo asistido:

Click en un nodo → usar el Asistente de flujo paso a paso
Mostrar cómo agrega actividades guiado

IA por texto:

Escribir en el panel IA: "agrega una decisión después de Validación"
Mostrar que el diagrama se actualiza

IA por voz:

Click en el micrófono del panel IA
Dictar: "conecta la actividad de Riesgos con el nodo final"
Mostrar que transcribe y aplica el cambio

Colaborativo:

Abrir segunda ventana con otro admin
Mover un nodo → se actualiza en tiempo real en la otra ventana


4. Admin — Diseñar formulario (2 min)

Click en "Diseñar formulario" de una actividad
Agregar campos manualmente
Mostrar Voz IA del formulario — dictar y que se rellene solo
Guardar

4. Funcionario — Completar actividad (4 min)

Entrar como Funcionario
Ver tareas pendientes (rojo/amarillo/verde)
Abrir una tarea → mostrar el formulario dinámico
Usar Voz IA — dictar el informe
Mostrar que los campos se rellenan automáticamente
Completar y enviar
Si hay gateway → mostrar el diálogo de decisión


5. Cliente móvil — Notificación (2 min)

Tener el celular visible
Al completar la actividad anterior → mostrar que llega la notificación instantánea
Abrir la app → ver el trámite actualizado


6. Admin — Análisis (2 min)

Ir a Análisis de cuellos de botella
Seleccionar la política
Mostrar el nodo crítico, tiempos por actividad, filtros


7. Cierre (1 min)

Resumir las innovaciones:

IA que edita diagramas por texto/voz
Voz que entiende y rellena formularios
Colaborativo en tiempo real
Notificaciones instantáneas al móvil
